# 🚀 Разбор задачи: Зеркальные строки (Оптимизация символов)

### 💡 Идея решения
Задача гораздо интереснее предыдущих, так как требует независимой посимвольной оптимизации. 

Поскольку выбор символа для конкретной позиции влияет **только на саму эту позицию и её зеркальное отражение** с конца строки, мы можем применить жадный перебор:
1. **Приведение к регистру:** Сначала переводим обе строки в нижний регистр с помощью `tolower`. (Да, в условии написано, что строки состоят только из символов латинского алфавита в нижнем регистре, но я не вчитался во время виртуального раунда, простите)
2. **Позиционный перебор (для `n / 2` элементов):** Для каждой позиции `i` мы рассматриваем 4 символа: `s1[i]`, `s2[i]` и их зеркальные пары `s1[n - i - 1]`, `s2[n - i - 1]`. Перебираем все 26 букв латинского алфавита, чтобы найти такой символ, суммарное расстояние до которого будет минимальным.
3. **Обработка центрального элемента:** 
   > **📌 Примечание:** Если длина строки `n` нечетная, центральный символ не имеет зеркальной пары. Мы находим оптимальный ответ для `n / 2` отдельно (учитывая только `s1[n / 2]` и `s2[n / 2]`) и выводим его ровно посередине итоговой строки.
4. **Сборка результата:** Формируем первую половину строки, выводим её, затем (если нужно) центральный символ, и после — зеркально развернутую первую половину.

---

### 💻 Код решения (C++)

```cpp
#include <bits/stdc++.h>
/*
 author: The Pinnacle
*/
 
using namespace std;
using ll = long long;
using ld = long double; 

void solve() {
    int n; cin >> n;
    string s1; cin >> s1; 
    string s2; cin >> s2;
    
    for (int i = 0; i < n; i++) s1[i] = tolower(s1[i]);
    for (int i = 0; i < n; i++) s2[i] = tolower(s2[i]);
    
    string res = "";
    
    // Перебор для левой половины строки (с учетом зеркальных позиций)
    for (int i = 0; i < n / 2; i++) {
        int min_diff = INT_MAX;
        char c = '-1';
        
        int a = s1[i] - 'a';
        int b = s2[i] - 'a';
        int d = s1[n - i - 1] - 'a';
        int e = s2[n - i - 1] - 'a';
        
        for (int j = 0; j < 26; j++) {
            int current_diff = abs(a - j) + abs(b - j) + abs(d - j) + abs(e - j);
            if (current_diff < min_diff) {
                min_diff = current_diff;
                c = char(j + 'a');
            }
        }
        res += c;
    }
    
    cout << res; // Выводим первую половину
    
    // Обработка центрального элемента для нечетной длины
    if (n & 1) {
        int min_diff = INT_MAX;
        char c = '-1';
        
        int a = s1[n / 2] - 'a';
        int b = s2[n / 2] - 'a';
        
        for (int j = 0; j < 26; j++) {
            if (abs(a - j) + abs(b - j) < min_diff) {
                min_diff = abs(a - j) + abs(b - j);
                c = char(j + 'a');
            }
        }
        cout << c; // Выводим центр
    }
    
    // Переворачиваем первую половину, чтобы получить корректную правую часть
    reverse(res.begin(), res.end());
    cout << res << '\n';
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    solve();
    
    return 0;
}
```
