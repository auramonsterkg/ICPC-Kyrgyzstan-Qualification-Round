# 🚀 Разбор задачи: Проверка ограничений (TL и ML)

### 💡 Идея решения
Еще один представитель задач, которые максимально удобно решать с помощью **Python** по той же причине, что и предыдущую (встроенная длинная арифметика защищает от переполнения при перемножении больших чисел). 

По своей сути задачи очень похожи: у нас есть фиксированные константы ограничений, зависящие от выбранного языка программирования, и нам нужно просто рассчитать итоговые значения ресурсов (`a` для времени/операций и `b` для памяти) и сверить их с лимитами.

---

### 💻 Код решения (Python)

```python
n = int(input())
q = int(input())
k = int(input()) 

# Расчет затрат ресурсов
a = n * (q * 2) + n * (k * 5)
b = n * k

lang = str(input())

# Определение лимита операций в секунду в зависимости от языка
maxCnt = 500000000
if lang == 'java':
    maxCnt = 100000000
elif lang == 'py':
    maxCnt = 20000000

# Проверка на Time Limit (TL) и Memory Limit (ML)
if a > maxCnt and b > 20000000:
    print('TL and ML')
elif a > maxCnt:
    print('TL')
elif b > 20000000:
    print('ML')
else:
    print('OK')
```
