# 🚀 Разбор задачи: Определение типов данных

### 💡 Идея решения
Главное в этой задаче — выбрать наиболее удобный инструмент. В данном случае это **Python** благодаря встроенной **длинной арифметике** (поддержке работы с числами произвольной точности из коробки). 

В отличие от C++, где переполнение типов данных может привести к ошибкам или потребовать написания громоздких структур, в Python достаточно сохранить все системные константы ограничений в переменные и напрямую сверять с ними результаты операций `A`, `B` и `C`.

> **⚠️ Важное примечание:** Если тип данных `C` превосходит 32 бита, то тип данных `A` или `B` (в зависимости от того, какое число больше) будет автоматически соответствовать типу данных переменной `C`.

---

### 💻 Код решения (Python)

```python
# Константы для проверки диапазонов типов данных
INT_MAX = 2147483647
INT_MIN = -2147483648
LLONG_MIN = -9223372036854775808
LLONG_MAX = 9223372036854775807

a = int(input())
b = int(input())

c = a * b

if a >= b:
    if INT_MIN <= c <= INT_MAX:
        print(32)
    elif LLONG_MIN <= c <= LLONG_MAX:
        print(64)
    else:
        print(128)
else:
    if INT_MIN <= a <= INT_MAX:
        print(32)
    elif LLONG_MIN <= a <= LLONG_MAX:
        print(64)

if a < b:
    if INT_MIN <= c <= INT_MAX:
        print(32)
    elif LLONG_MIN <= c <= LLONG_MAX:
        print(64)
    else:
        print(128)
else:
    if INT_MIN <= b <= INT_MAX:
        print(32)
    elif LLONG_MIN <= b <= LLONG_MAX:
        print(64)

if INT_MIN <= c <= INT_MAX:
    print(32)
elif LLONG_MIN <= c <= LLONG_MAX:
    print(64)
else:
    print(128)
```
