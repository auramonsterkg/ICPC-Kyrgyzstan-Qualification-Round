# Моделирование таблицы результатов IOI

## 📝 Описание задачи
В данной задаче необходимо промоделировать работу турнирной таблицы по правилам IOI (спортивное программирование). На вход подаются логи посылок команд, по которым нужно рассчитать итоговые места участников.

### Правила ранжирования:
1. **Количество задач**: выше находится команда, решившая большее число задач.
2. **Штрафное время**: при равном количестве задач выше находится команда с меньшим штрафом.
3. **Идентификатор (ID)**: если совпадают и задачи, и штраф, команды выводятся в порядке возрастания их номеров.
4. **Разделение мест**: команды с абсолютно одинаковым результатом (кол-во задач и штраф) делят одно и то же место.

---

## 💡 Разбор решения

1. **Сбор данных**: Информация о посылках распределяется по трехмерному динамическому массиву `a[team][problem][info]`. Мы храним три параметра:
   * `a[team][problem][0]` — количество неудачных попыток до сдачи задачи.
   * `a[team][problem][1]` — минута сдачи задачи (\(M\)).
   * `a[team][problem][2]` — статус задачи (1, если сдана, и 0 в противном случае).
   Если задача уже была принята (`status == 1`), то любые последующие посылки по ней полностью игнорируются согласно правилам.

2. **Расчет результатов**: За время \(O(n \cdot p)\) для каждого участника вычисляется суммарное количество решенных задач и итоговый штраф. Штраф считается только для успешно сданных задач по стандартной формуле ICPC: `время_сдачи + 20 * неудачные_попытки`.

3. **Сортировка**: Используется кастомный компаратор для функции `std::sort`. Он последовательно проверяет три критерия для обеспечения стабильности и выполнения свойства *Strict Weak Ordering*:
   * Сначала сравнивает решенные задачи (по убыванию).
   * При равенстве задач сравнивает штрафное время (по возрастанию).
   * При полном равенстве результатов сравнивает ID команд (по возрастанию).

4. **Ранжирование мест**: Логика финального вывода учитывает разделение мест. Если текущая команда по количеству задач и штрафу полностью совпадает с предыдущей в таблице, она делит с ней текущее место (`cur_place`). Если результат хуже — её место становится равным её реальной позиции в массиве (индекс \(+ 1\)).

---

## 📊 Сложность алгоритма

* **Временная сложность**: \(O(q + n \cdot p + n \log n)\), где:
  * \(q \le 10^5\) — количество запросов (считывание лога посылок).
  * \(n \le 10^3\) — количество команд.
  * \(p \le 20\) — количество задач.
  Сортировка выполняется за \(O(n \log n)\). Данный подход мгновенно отрабатывает в рамках 1 секунды.
* **Сложность по памяти**: \(O(n \cdot p)\) для хранения истории посылок. Для максимальных ограничений массив занимает менее 2 МБ, что с огромным запасом проходит в лимит 256 МБ.

## 💻 Исходный код (C++)

```cpp
#include <bits/stdc++.h>
/*

*/
 
using namespace std;
using ll = long long;
using ld = long double; 

void solve() {
    ll n, p; cin >> n >> p; 
    // a[team][problem] = {неудачные_попытки, время_сдачи, сдана_ли(0 или 1)}
    vector<vector<vector<ll>>> a(n, vector<vector<ll>>(p, vector<ll>(3, 0)));
    
    ll q; cin >> q;
    while(q --> 0) {
        ll m, id, t, v; cin >> m >> id >> t >> v; 
        if(a[id - 1][t - 1][2]) continue; // Если задача уже сдана, игнорируем
        if(v) {
            a[id - 1][t - 1][1] = m; 
            a[id - 1][t - 1][2] = v;
        } else {
            a[id - 1][t - 1][0]++;
        }
    }
    
    // ans[i] = {id, кол-во задач, штрафное время}
    vector<vector<ll>> ans(n, vector<ll>(3));
    for(ll i = 0; i < n; i++) {
        ans[i][0] = i + 1;
        for(ll j = 0; j < p; j++) {
            if(!a[i][j][2]) {
                continue;
            }
            
            ans[i][1]++; 
            ans[i][2] += a[i][j][1] + a[i][j][0] * 20;
        }
    }
    
    // Кастомный компаратор по правилам ICPC
    sort(ans.begin(), ans.end(), [](const vector<ll>& a, const vector<ll>& b) {
        if (a[1] == b[1]) {
            if(a[2] == b[2]) return a[0] < b[0]; // Меньше ID -> выше
            return a[2] < b[2];                  // Меньше штраф -> выше
        }
        return a[1] > b[1];                      // Больше задач -> выше
    });
    
    // Корректный расчет и вывод мест с учетом деления позиций
    ll cur_place = 1;
    for(ll i = 0; i < ans.size(); i++) {
        if (i > 0 && (ans[i][1] != ans[i-1][1] || ans[i][2] != ans[i-1][2])) {
            cur_place = i + 1; 
        }
        
        cout << cur_place << ' ' << ans[i][0] << ' ' << ans[i][1] << ' ' << ans[i][2] << '\n';
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    solve();
    
    return 0;
}
```
