# 🚀 Разбор задачи: Распределение загрузки

### 💡 Идея решения
Ограничения в задаче позволяют написать перебор за **квадратичное время (O(N * P))**. Воспользуемся этим и реализуем алгоритм в строгом соответствии с условием.

1. **Разделение данных:** Сначала считаем входные потоки в два двумерных массива (матрицы): один содержит *статус задачи*, а другой — *количество попыток*.
2. **Поячеечный перебор:** Будем использовать их, перебирая каждую ячейку для получения ответов:
   * **Количество команд, сдавших задачу:** проходим по всем командам и ищем те, у которых статус задачи равен `'+'`.
   * **Количество команд, сделавших хотя бы одну попытку:** проходим по командам и считаем тех, у кого выполняется хотя бы одно из условий:
     1. Статус **не равен** `'-'`
     2. Количество попыток **не равно** `0`
   * **Суммарное количество попыток:** просто прибавляем текущее значение попыток из соответствующего массива к общему счетчику задачи.

### 💻 Код решения (C++)

```cpp
#include <bits/stdc++.h>
/*

*/
 
using namespace std;
using ll = long long;
using ld = long double; 

void solve() {
    int n, p; cin >> n >> p;
    vector<vector<int>> cnt(n, vector<int>(p));
    vector<vector<char>> res(n, vector<char>(p));
    
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < p; j++) {
            cin >> res[i][j] >> cnt[i][j];
        }
    }
    
    vector<vector<int>> ans(p, vector<int>(3));

    for (int i = 0; i < p; i++) {
        for (int j = 0; j < n; j++) {
            if (res[j][i] == '+') ans[i][0]++; 
            if (res[j][i] != '-' || cnt[j][i]) ans[i][1]++;
            ans[i][2] += cnt[j][i]; 
        }
    }
    
    for (int i = 0; i < p; i++) {
        for (int j = 0; j < 3; j++) {
            cout << ans[i][j] << ' ';
        }
        cout << '\n';
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    solve();
    
    return 0;
}
```
